# 🎥 Tella TV MCP Server

> A **Model Context Protocol (MCP) server** for [Tella TV](https://tella.com) — lets AI assistants like Claude control Tella video workflows, plan cinematic zoom annotations, manage playlists, and set up webhooks.

[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Node.js](https://img.shields.io/badge/node-%3E%3D18-green)](https://nodejs.org)
[![MCP](https://img.shields.io/badge/protocol-MCP%201.0-purple)](https://modelcontextprotocol.io)

---

## ✨ Features

| Tool | Description |
|------|-------------|
| `tella_list_videos` | List all videos with pagination & playlist filter |
| `tella_get_video` | Full video details — transcript, chapters, embed links |
| `tella_list_playlists` | List all playlists in your workspace |
| `tella_list_webhooks` | View all configured webhook endpoints |
| `tella_create_webhook` | Subscribe to Tella events (`video.created`, `export.ready`) |
| `tella_delete_webhook` | Remove a webhook endpoint |
| `tella_add_zoom_annotation` | 🔍 Plan a cinematic zoom/focus point (timestamp + screen coords) |
| `tella_get_zoom_annotations` | Retrieve all planned zoom points for a video |
| `tella_clear_zoom_annotations` | Reset the zoom plan for a video |
| `tella_export_zoom_script` | Export a human-readable recording script with all zoom cues |

## 🚀 Quick Start

### 1. Get your Tella API Key

1. Go to **[tella.com](https://tella.com)** → Your Workspace → **Settings → API**
2. Generate a new API key
3. Copy it — you'll need it below

### 2. Install & Build

```bash
git clone https://github.com/AprailRain-py/tella-tv-mcp-server.git
cd tella-tv-mcp-server
npm install
npm run build
```

### 3. Run the server

```bash
TELLA_API_KEY=your_api_key_here npm start
```

    }
  }

## 🎬 Zoom Annotation Workflow (Product Recording)

The killer feature of this MCP server is **pre-planning your Tella zoom effects** before you even hit record.

### Example: Planning a Definable product demo

```
You → AI: "Plan zoom annotations for my Definable product demo video"

AI calls: tella_add_zoom_annotation
  - timestamp: 3s,  x: 50, y: 20, zoom: 2.0, label: "Hero headline — Definable"
  - timestamp: 12s, x: 30, y: 60, zoom: 2.5, label: "Click 'Add Budget' button"
  - timestamp: 25s, x: 70, y: 45, zoom: 3.0, label: "Transaction detail panel"
  - timestamp: 40s, x: 50, y: 50, zoom: 1.5, label: "Dashboard overview"

AI calls: tella_export_zoom_script → outputs your recording cue sheet
```

### Exported Script Example

```
// Tella Zoom Script — Video: definable-demo-v1
// Generated by tella-tv-mcp-server

// Step 1 @ 3s    — Zoom 2.0x at (50%, 20%) [Hero headline — Definable]
// Step 2 @ 12s   — Zoom 2.5x at (30%, 60%) [Click 'Add Budget' button]
// Step 3 @ 25s   — Zoom 3.0x at (70%, 45%) [Transaction detail panel]
// Step 4 @ 40s   — Zoom 1.5x at (50%, 50%) [Dashboard overview]
```

Use this cue sheet during your Tella recording session to apply zoom effects at exactly the right moments.
